## Concepts of Note

| Path                     | Description                          | Notes                                                                                                                    |
| ------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `.`                      | Project root                         | The directory containing your `pyproject.toml`; this is where you run `uv run`, `uv add`, etc.                           |
| `pyproject.toml`         | Project metadata and dependencies    | Defines `[project]` (name, version, dependencies, entry points), `[tool.uv]` (uv-specific config), and `[build-system]`. |
| `uv.lock`                | Lock file generated by uv            | Lists resolved dependencies and their versions; committed to version control for reproducibility.                        |
| `src/`                   | Source directory                     | Recommended modern Python layout — avoids import shadowing issues.                                                       |
| `src/<package_name>/`    | Your package’s code                  | Contains the actual Python modules for your package. Example: `src/my_app/__init__.py`.                                  |
| `tests/`                 | Test directory                       | Typically holds unit and integration tests, often discovered automatically by pytest.                                    |
| `.venv/`                 | Local virtual environment (optional) | Created by `uv venv` or automatically managed; usually ignored in `.gitignore`.                                          |
| `.gitignore`             | Git ignore file                      | Should include `.venv/`, `__pycache__/`, `*.pyc`, and other build artifacts.                                             |
| `README.md`              | Project readme                       | Explains usage, installation, and development notes.                                                                     |
| `LICENSE`                | License file                         | Defines open-source or proprietary licensing terms.                                                                      |
| `scripts/` _(optional)_  | Helper or CLI scripts                | Useful for dev tooling or examples (if not part of the main package).                                                    |
| `examples/` _(optional)_ | Usage examples                       | Demonstrates API usage or application setup.                                                                             |
| `docs/` _(optional)_     | Documentation files                  | Sphinx, MkDocs, or other docs systems can live here.                                                                     |

## Examples
Structure:
```
my_project/
├── pyproject.toml
├── src/
│   └── my_project/
│       ├── __init__.py
│       ├── main.py
│       ├── utils.py
│       ├── config/
│       │   ├── __init__.py
│       │   └── loader.py
│       └── core/
│           ├── __init__.py
│           └── engine.py
```
imports
```python
from my_project.utils import some_function
from my_project.config.loader import load_config
from my_project.core.engine import Engine
```
pyproject.toml
```toml
[project.scripts]
my-app = "my_project.main:main"
```
Entry point
```bash
uv run my-app
```

## Usage
 `uv run --with jupyter jupyter lab` ;;; Run jupyter from a uv virtual environment

# Additional Background
## Usage

 `jupyter kernelspec list` ;;; Lists all kernels Jupyter understands
 `python -m ipykernel install --user --name venv --display-name "Python (venv)"` ;;; Add a new python kernel associated with your kernel environment `venv`
 `jupyter kernelspec remove envii` ;;; Remove a kernel named `envii`

- [p] `%store var` ;;; Save jupyter variable `var` to disk

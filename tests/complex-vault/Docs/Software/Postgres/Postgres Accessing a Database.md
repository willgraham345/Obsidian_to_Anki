# Additional Background
## Usage
  `psql -U <user> <db_name>` ;;; Access and start up a PostgreSQL database with an interactive SQL terminal and specify the user 
  `psql -U <user> -W <db_name>` ;;; Access and start up a PostgreSQL database with an interactive SQL terminal and specify the user, asking it to prompt you for the password.

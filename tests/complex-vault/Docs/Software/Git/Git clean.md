# Background
Operates on untracked files

## Usage
  `git clean` ;;; Remove untracked changes = #tools/git/clean_reset = `-n` Perform a "dry run", showing what will be removed 


      `-f` Force deletion of untracked files
      `-d` Force deletion of untracked directories

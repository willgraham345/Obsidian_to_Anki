## CrazyfliePublisher
Overview
- Work needs to be done at step 5

Attributes:
- `_link_uri : str`
- `lh1_ros2_pose_frame : str`
- `lh2_ros2_pose_frame : str`
- `lh_pose_reader : LighthousePoseReader()`
- `_initial_translation : str`
- `_initial_orientation_quaternion : str`
- `cf : Crazyflie`
	- `scf : SyncCrazyflie`

Methods:
- `__init__()`
	1. Initialize class Members
		1. Members that will be initialized later (lighthouse stuff + buffers)
		2. Ros2 publishers/subscribers + tf2 broadcaster
			1. `create_subscription('/cmd_vel')`
	3. Initialize Lighthouse Pose listeners
	4. Instantiate Crazyflie
		1. Crazyflie values + flags
		- Creates `cf`, `scf`, `_timer_lh_pose_listener`
		- `set_initial_position()`
	5. `_init_lh_config_manager()` 
		1. `lh_pose_reader.get_lh_geo_data()`
		2. Initializes `lh_config_writer`
		- I want it to let `_on_timer_lh_pose_callback()` handle writing geometry data to cf
	6. Loop
		- `sendHoverCommand()`
		- `_timer_lh_pose_callback()`
			- Writes `transform` object based on reading lh frames
			- Creates poses
			- Passes poses to `parse_poses()` from LighthouseConfigManager
- `_on_timer_lh_pose_callback()`
	- Calls `get_lh_geo_data()`
- `_connected()`
	- Sets crazyflie logs and callbacks

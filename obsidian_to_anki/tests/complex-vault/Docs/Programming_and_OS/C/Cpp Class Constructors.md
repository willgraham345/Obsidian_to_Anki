# Additional Background
## Concepts of Note
- Invoked automatically at object creation; initializes data members of new objects.
- Typically defined in the `public` section, but can be defined outside the class body.

󰙎 Constructor overloading ;; Multiple constructors in the same class with different parameter lists — lets the object be initialized differently depending on arguments passed.
󰙎 Default constructor ;; Takes no arguments. Either explicitly defined or compiler-generated (implicit).
󰙎 Implicit default constructor ;; No-argument constructor generated by the compiler when no constructors are defined. Removed as soon as any user-defined constructor is declared. [cppreference](https://en.cppreference.com/w/cpp/language/default_constructor.html)
󰙎 Delegated constructor ;; Constructor that forwards initialization to another constructor in the same class. Improves reuse and simplifies maintenance.
󰙎 Initialization list ;; Member-initialization syntax that runs before the constructor body. Members initialize in declaration order, not initializer-list order.
󰙎 explicit constructor ;; Constructor marked `explicit` to prevent the compiler from using it for implicit single-argument type conversions. Required on any single-arg constructor where silent coercion would be dangerous.

## Syntax

### Default Constructor
No arguments. `= default` tells the compiler to default-initialize all members and call any base-class default constructors; no init list required.

```cpp
class MyClass {
public:
    MyClass() = default;  // compiler-generated default init
};

// Implicit default constructor (no constructors defined at all)
class MyClass {
    int x;
    double y;
    // compiler generates MyClass() implicitly
};

int main() {
    MyClass obj;  // default constructor called
}
```

### Parameterized Constructor
Uses one or more parameters to initialize an object with specific values. When subclassing, derived must explicitly call the base parameterized constructor in its init list.

[cppreference — constructors](https://en.cppreference.com/w/cpp/language/constructor)

```cpp
// Inline definition
className(parameters...) {
    // body
}

// Separated definition with init list
MyClass::MyClass(int val) : memberVar(val) {}

// Multi-member init list
MyClass::MyClass(int a, int b)
    : memberVar1(a),
      memberVar2(b) {}
```

#### Base and Derived Class
```cpp
class Base {
public:
    int id;
    Base(int id_val) : id(id_val) {}
    // Defining any constructor suppresses the implicit Base()
};

class Derived : public Base {
public:
    double cost;
    // Must explicitly call Base parameterized constructor
    Derived(int id_val, double cost_val) : Base(id_val), cost(cost_val) {
        // Derived body runs after Base is fully constructed
    }
};
```

### Initialization List Constructor
Members initialized before the constructor body executes. Members always initialize in **declaration order**, regardless of order in the initializer list.

```cpp
ClassName(type1 param1, type2 param2) : member1(param1), member2(param2) {
    // Constructor body (runs after init list)
}
```

```cpp
ClassName::ClassName(
	int num = 5,
	std::string str = "Taco")
	:  m_num(num),
		m_str(str)
	{
	}
```

### Copy Constructor
Defines how to copy an instance of the class. Takes a const reference to another instance of the same type.

- If no copy constructor is defined and you need to work with a vector, see [[Cpp std vector#Vector Methods|`.emplace()`]].

```cpp
ClassName(const ClassName& obj) {
    // copy logic
}
```

### Move Constructor
Defines how to move an instance — transfers ownership of resources rather than copying. Takes an rvalue reference (`&&`). See [[Cpp std move]] for rvalue reference details.

```cpp
ClassName(ClassName&& obj) noexcept {
    // transfer ownership of obj's resources
}
```

### Overloaded Constructors
Define multiple constructors with different parameter signatures. Implements the [[Factory Method]] pattern — callers select behavior via argument types/count.

```cpp
// Rectangle: no-arg vs two-arg
class Rectangle {
    int width, height;
public:
    Rectangle();
    Rectangle(int a, int b);
    int area() { return width * height; }
};

Rectangle::Rectangle()          { width = 5; height = 5; }
Rectangle::Rectangle(int a, int b) { width = a; height = b; }

int main() {
    Rectangle rect(3, 4);   // area = 12
    Rectangle rectb;        // area = 25
}
```

```cpp
// ListNode: three overloads via init list
struct ListNode {
    int val;
    ListNode* next;
    ListNode()                          : val(0),  next(nullptr) {}
    ListNode(int x)                     : val(x),  next(nullptr) {}
    ListNode(int x, ListNode* next)     : val(x),  next(next)    {}
};
```

### Delegated Constructors
One constructor calls another in the same class via the init-list syntax. Chains initialization, avoids duplicated logic.

```cpp
class MyClass {
    int x, y;
public:
    MyClass(int x, int y) : x(x), y(y) {}          // primary
    MyClass(int x)        : MyClass(x, 0) {}        // delegates to primary
    MyClass()             : MyClass(0, 0) {}        // delegates to primary
};
```

### explicit
Prevents the compiler from using a single-argument constructor for implicit type conversions. Without `explicit`, any value convertible to the parameter type can silently construct an object — often unintended. See [[Cpp explicit]].

```cpp
class String {
public:
    explicit String(int n);         // allocates n bytes — explicit blocks silent int→String coercion
    String(const char* p);          // implicit conversion from char* is intentional here
};

String s1 = 'x';        // compile error: 'x' (char→int) cannot implicitly call String(int)
String s2(10);           // OK: direct initialization
String s3 = "hello";    // OK: String(const char*) is not explicit
```

- Apply `explicit` to any single-arg constructor where silent coercion would be a bug.
- Also valid on multi-arg constructors to block aggregate-style brace/paren implicit construction (C++11+).

### Template Constructors

## Usage
 `class-name() = default;` ;;; Tells the compiler to default-initialize all members and call base default constructors. No init list needed; body can be empty.
 `Rectangle(int w, int h) : width(w), height(h) {}` ;;; Init-list constructor for `Rectangle` — initializes `width` and `height` before body runs.
 `A(A&&) = delete;` ;;; Deletes the move constructor for class `A`.
 `A(const A&) = delete;` ;;; Deletes the copy constructor for class `A`.
 `A& operator=(A&&) = delete;` ;;; Deletes the move assignment operator for class `A`.
 `A& operator=(const A&) = delete;` ;;; Deletes the copy assignment operator for class `A`.

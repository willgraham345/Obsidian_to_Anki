# Additional Background
## Concepts of Note
Bitwise takes two equivalent length bit designs as boundaries. If the two bits in the looked-at position are 0, the next bit is zero. If not, it is 1.

## Usage
  `a & b` ;;; Bitwise AND operator (bit representation of ints)
  `a ^ b` ;;; Bitwise NOT operator (bit representation of ints)
  `a and b` ;;; Logical operator, combining two logical statements
